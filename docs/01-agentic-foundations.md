
# OpsPilot — Agentic AI Foundations

## 1. Project Goal

OpsPilot is an AI-powered IT support agent that investigates
IT incidents, retrieves relevant documentation, performs
controlled diagnostics, and assists with resolution.

## 2. Why an Agent?

Explain why a simple chatbot or fixed workflow is
insufficient for this project.

## 3. Agent Capabilities

- Incident understanding and classification
- Clarifying questions
- Knowledge retrieval
- Diagnostic tool selection
- Troubleshooting planning
- Resolution verification
- Ticket creation and escalation

## 4. Agent Boundaries

List what the agent can do independently and what
requires deterministic validation or human approval.

## 5. Hybrid Architecture

Explain which responsibilities belong to the agent
and which belong to the application backend.

## 6. Example Scenario

Describe how OpsPilot handles:
"I cannot connect to the company VPN."

## 7. Key Design Principles

- Bounded autonomy
- Validated tool execution
- Human approval for consequential actions
- Observable results
- Resolution verification
